# Dataset Card: SAfriSenti Corpus Verification Sample

## Dataset Name

SAfriSenti Corpus — Balanced Verification Sample

## Purpose

This sample was prepared to verify the existence and structure of SAfriSenti language datasets used for multilingual sentiment analysis in South African under-resourced languages.

## Supported Task

Three-class sentiment classification:

- Positive
- Negative
- Neutral

## Languages Included in This Pack

- Sepedi
- Setswana
- Sesotho
- isiXhosa

The isiZulu source file was not included in the current upload and can be added when provided.

## Data Source

The records are derived from social media text, primarily Twitter, and reflect informal multilingual language use and English code-switching.

## Annotation

The dataset was developed using a combination of manual annotation, native-speaker validation, sentiment lexicons, distant supervision, emoji-based labelling, sentiment-bearing word-based labelling, and SentiApp-assisted annotation.

## Sample Selection

This verification sample prioritises easy-to-read records with English code-switching. The selection is balanced by language and sentiment category.

## Intended Use

The sample is intended for:

- dataset verification;
- examiner/school review;
- repository documentation;
- reproducibility checks;
- demonstration of label structure.

## Non-Intended Use

This sample should not be used as a complete replacement for the full SAfriSenti corpus. It is a small verification subset and may not reflect the full distribution of the original dataset.

## Limitations

The sample is limited to the four uploaded language files. It also prioritises readable English-code-switched examples, so it is not intended to represent the full linguistic complexity of the complete corpus.

## Responsible Use

The dataset should not be used for high-stakes decisions about individuals, automated surveillance, political targeting, or punitive decisions without human oversight, ethical approval, and fairness evaluation.
