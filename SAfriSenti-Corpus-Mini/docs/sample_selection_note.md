# Balanced Sample Selection Note

This verification sample contains 1,500 records from the SAfriSenti corpus: 300 records per language and 100 records per sentiment category.

The selected languages are Sepedi, Setswana, Sesotho, isiXhosa, and isiZulu. Each language sample contains 100 positive, 100 negative, and 100 neutral records.

The samples were filtered to favour easier-to-read short or medium-length sentences, exclude URLs and user mentions, and include visible English code-switching. The source is described as Twitter, consistent with the original dataset publications.
